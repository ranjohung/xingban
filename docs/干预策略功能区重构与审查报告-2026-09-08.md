# 干预策略功能区重构与审查报告

> 日期：2026-09-08
> 审查视角：孤独症及伴随情绪、睡眠、攻击、自伤、抑郁或躁狂风险儿童的家长
> 安全边界：家庭策略不能替代儿科、儿童精神科、临床心理、急救或警方处置。

## 1. 原问题复核

原功能区以策略名称和技术分类为入口，家长必须先知道“该用什么方法”；虽然 10 套教程已有步骤，但缺少按孩子当前行为定位、原因线索、停止条件和高危分流。对正在承受压力的家长而言，查找成本高，且普通“有效/无效”反馈容易被错误套用到精神科或医疗危机。

## 2. 已完成重构

- 首屏改为“孩子现在正在发生什么”，先安全判断，再按行为查找。
- 建立 15 类入口、20 套教程：哭闹/爆发、攻击/扔物、自伤、跑开/走失、拒绝/转换、沟通受挫、焦虑/过载、进食、睡眠、低落退缩、异常兴奋少睡、意识/药物、生活自理、社交及全部情况。
- 搜索覆盖策略名、具体动作、场景、目标、观察点、停止条件和后续计划，支持“撞头、捂耳、突然不睡觉”等家长语言。
- 每个详情统一包含适用条件、方案目标、观察点、停止条件、后续计划、开始准备、5—6 步操作、可照读话术、禁忌和危机提示。
- 高危分类显示红色总分流提示，并提供直接进入紧急支持的入口。
- 自伤、走失、异常兴奋少睡、意识异常和药物事件不再提供“有效/一般/无效”评价，改为医疗安全分流。

## 3. 覆盖矩阵

| 家长看到的情况 | 对应路径 | 首要目标 |
|---|---|---|
| 哭闹、尖叫、倒地 | 情绪爆发降载 | 降刺激、保安全、恢复一个小选择 |
| 推打、踢咬、扔物 | 攻击安全处置 | 拉开距离、撤离他人、判断是否报警/急救 |
| 撞头、咬手、掐颈 | 自伤安全响应 | 伤情判断、持续陪同、急救与自杀风险询问 |
| 冲门、道路/水边跑开、走失 | 跑开走失方案 | 恢复目视、报警、按高危地点分工 |
| 结束屏幕、上学或洗澡抗拒 | 拒绝与转换 | 预告、真实选择、降低第一步门槛 |
| 捂耳、逃离噪声、感官过载 | 感官安抚 | 找刺激源、一次一个选择、不强抱 |
| 挑食、拒食、呛咳 | 进食分级 | 排除吞咽/营养风险，再做接触阶梯 |
| 入睡困难、夜醒、突然少睡 | 睡眠观察 | 建立记录；少睡伴兴奋立即精神科分诊 |
| 持续低落、兴趣下降、绝望表达 | 低落退缩支持 | 直接询问自杀风险、陪伴并转介 |
| 极少睡眠、话多、冲动冒险 | 异常兴奋分诊 | 停止刺激、不自行改药、尽快精神科评估 |
| 幻觉、严重混乱、服药过量 | 医疗事件处置 | 立即急救，不使用家庭训练替代 |

## 4. 批判性安全结论

不能承诺家长“遇到任何情况都能在应用内解决”。更可靠的完整性是：常见情况能找到可执行路径；无法分类时有观察方法；危险或不确定时能立刻退出教程并进入急救/专业支持。当前版本已达到这一信息架构目标，但所有医疗与干预内容在生产发布前仍需儿童精神科、临床心理、行为分析、儿科营养/吞咽及危机干预专业复核。

## 5. 验收

移动视口实际验证策略首页、横向行为筛选、“兴奋/少睡”高危分类及详情。详情完整显示分诊按钮、目标、观察点、停止条件、后续计划、准备、6 步处置、话术和禁忌；控制台 0 error、0 warning。专项脚本验证 20 套教程、15 类入口和高危分流标记。

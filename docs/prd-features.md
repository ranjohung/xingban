## 模块0：儿童数字孪生档案

**功能概述**: 为每个孩子建立多维能力画像，涵盖诊断报告、能力评估、感官偏好、强化物清单、医疗信息等。AI根据档案生成初始干预目标，所有个性化推荐以此为基础。

**核心字段定义**:

| 字段类别 | 字段名 | 类型 | 说明 |
|----------|--------|------|------|
| 基础信息 | 昵称 | String | 必填 |
| 基础信息 | 出生日期 | Date | 必填 |
| 基础信息 | 诊断类型 | Enum | ASD/ADHD/DD/OTHER |
| 能力评估 | 沟通水平 | Enum | 无口语/单词/短语/句子/流畅 |
| 能力评估 | 社交水平 | Int(1-5) | 1=完全无互动，5=主动社交 |
| 能力评估 | 自理水平 | Int(1-5) | 1=完全依赖，5=完全自理 |
| 能力评估 | 认知水平 | Int(1-5) | 1=严重落后，5=同龄水平 |
| 感官特点 | 听觉/视觉/触觉/前庭 | Enum | 敏感/迟钝/寻求/回避/正常 |
| 强化物 | 物品+活动 | JSON数组 | 如["泡泡水","举高高"] |
| 医疗信息 | 过敏/用药 | String | 可选 |

**档案创建向导流程（4步）**:

1. **步骤1：基础信息** — 输入昵称、出生年月、选择诊断类型（ASD/ADHD/DD/OTHER）
2. **步骤2：能力快速评估** — 选择题形式评估沟通、社交、自理、认知四个维度（非标准化量表，降低填写门槛）
3. **步骤3：感官特点** — 多选题选择听觉、视觉、触觉、前庭四方面的特点（敏感/迟钝/寻求/回避/正常）；填写强化物清单（孩子喜欢的物品和活动）
4. **步骤4：完成与初始画像** — 系统生成"初始干预画像"摘要卡片，展示能力雷达图，AI自动生成3条初始干预目标建议

**边界情况**:
- 档案创建过程中可随时保存草稿，72小时内完成
- 诊断类型选择"OTHER"时，需手动输入并说明
- 能力评估数据不足时，使用年龄默认值作为初始模板
- 档案创建后允许随时修改，修改后AI自动更新干预目标建议
- 支持多子女档案（最多绑定3个孩子），切换角色时档案数据隔离

## 模块1：一键记录与AI结构化

**功能概述**: 支持语音/文字/拍照三种输入方式，AI自动分析行为类型、情绪状态、触发因素，生成结构化记录，并关联历史行为数据形成图谱。

**UX流程**:
1. 首页点击"记录"按钮
2. 选择输入方式：语音/文字/拍照
3. **语音输入**: 长按录音，最长120秒，松手自动上传识别
   - 语音识别失败容错流程：
     - 第1次失败：提示"网络有点慢，请重试"，自动重试一次
     - 第2次失败：提示"识别困难，是否切换文字输入？"，提供语音转文字修正入口
     - 第3次失败：自动切换为文字输入模式，保留音频文件待后续人工处理
4. **文字输入**: 文本框输入，支持字数统计（最多500字）
5. **拍照记录**: 拍摄现场照片，AI辅助识别场景，自动填充情境描述
6. AI自动分析并展示结果：行为类型、情绪状态、触发因素、行为功能、强度等级
7. 确认或编辑分类、标签、备注
8. 保存记录，自动关联历史行为记录，更新行为关联图谱

**行为分类标签体系（27种）**:

| 大类 | 子类 | 说明 |
|------|------|------|
| 情绪爆发 | 尖叫、哭闹、倒地、摔东西 | 情绪失控导致的爆发性行为 |
| 刻板行为 | 摇晃身体、转圈、拍手、排列物品 | 重复性、固定模式的行为 |
| 攻击行为 | 打人、踢人、咬人、抓头发 | 对他人具有攻击性的行为 |
| 自伤行为 | 撞头、咬自己、抓自己 | 对自己造成伤害的行为 |
| 跑开/走失 | 无预警跑开、躲藏 | 突然脱离成人视线范围 |
| 感官寻求 | 过度触摸、盯着光源、闻物品 | 寻求特定感官刺激 |
| 感官回避 | 捂耳朵、遮眼睛、拒绝触碰 | 回避特定感官输入 |
| 沟通尝试 | 用手指、拉人手、发出声音 | 试图表达需求或引起注意 |
| 适应性技能 | 自己穿衣、如厕、吃饭 | 生活自理相关行为 |
| 社交发起 | 主动靠近同伴、分享玩具 | 主动社交互动行为 |
| 进食问题 | 挑食、拒绝进食、进食过快 | 与进食相关的行为问题 |
| 睡眠问题 | 入睡困难、夜醒、早醒 | 与睡眠相关的行为问题 |
| 其他 | 用户自定义 | 不在上述分类中的行为 |

**历史行为关联图谱**:
- 展示同类行为发生的时间分布、触发因素关联、策略效果对比
- 支持按时间轴、行为类型、情绪状态筛选查看
- 点击节点可查看对应记录详情

**边界情况**:
- 无网络时本地暂存音频/图片，有网后自动上传
- 录音超过120秒自动截断并提示
- 放弃记录不保存数据，本地缓存可在24小时内恢复
- 分类可选"其他"，手动输入并提示运营审核后加入分类库

## 模块2：情景化即时策略推荐

**功能概述**: 基于行为记录和儿童档案，推荐3条个性化策略，包含步骤、话术、原理，支持反馈学习。

**UX流程**:
1. 记录保存后自动展示策略，也可从首页"获取策略"入口主动查询
2. 显示3张策略卡片，每张包含：名称、图标、适用说明、折叠的步骤/话术，喇叭朗读
3. 卡片底部："试过了吗？效果如何→" 点击展开表情反馈（😊有效/😐一般/😞无效）+选填笔记
4. 连续3次反馈无效，切换为共情模式，提供紧急模式跳转
5. 排序逻辑：历史最有效 → 最简单 → 进阶策略

**技能泛化追踪**:

场景：家长在餐桌场景学会了策略A，但不知道是否适用于超市、学校等其他场景。

- 当某个策略在特定场景被标记为"有效"超过3次后，系统自动提示："该策略在餐桌场景效果良好，是否尝试在以下场景使用？"
- 系统推荐2-3个相似场景（基于场景相似度算法）
- 推荐场景示例：餐桌 → 超市收银台、学校食堂、家庭聚餐
- 家长可选择"去试试"或"暂不尝试"
- 尝试新场景后，系统追踪策略在新场景的效果

**场景相似度匹配规则**:

| 原始场景 | 相似场景推荐 | 匹配理由 |
|----------|--------------|----------|
| 餐桌吃饭 | 超市收银台 | 涉及等待、规则遵守 |
| 餐桌吃饭 | 学校食堂 | 涉及集体用餐、社交互动 |
| 客厅游戏 | 公园玩耍 | 涉及社交互动、规则遵守 |
| 客厅游戏 | 教室课堂 | 涉及轮流、注意力维持 |
| 卧室睡前 | 午睡时间 | 涉及作息规律、情绪调节 |

**行为功能分析教学引导**:

当AI输出行为功能假设时（如"逃避型行为""求关注行为"），每条假设旁显示一个问号图标，点击后弹出教学卡片，用通俗语言解释专业术语：

| 功能类型 | 通俗解释 | 常见表现 |
|----------|----------|----------|
| 逃避型行为 | 孩子在说"我不想做这个" | 任务太难、时间太长、环境不适应时出现 |
| 求关注行为 | 孩子在说"看看我" | 即使被批评也是关注，孩子会重复做 |
| 感官刺激行为 | 孩子在说"我的身体需要这个感觉" | 摇晃、拍手、转圈等自我刺激行为 |
| 获取实物行为 | 孩子在说"我想要那个" | 通过哭闹、抢夺等方式获取喜欢的物品或活动 |

教学卡片设计：
- **标题**: "什么是逃避型行为？"
- **内容**: "孩子可能用这个行为来逃避不喜欢的任务。例如，不想洗澡所以尖叫。当任务太难或孩子疲惫时更常见。"
- 配简笔画风格插画（示意场景）
- 卡片底部提供"了解更多"链接，跳转家长学院相关课程

**干预一致性检查**:

系统检测到当前全生涯目标与推荐策略方向不一致时，在策略卡片顶部显示一致性提示卡片：

- 检测逻辑：将当前活跃目标的关键词（如"增加社交发起"）与策略方向标签（如"减少社交回避"）进行语义匹配
- 发现不一致时提示："该策略主要针对减少社交回避，而您当前的目标是增加主动社交发起。是否同时查看主动社交相关的策略？"
- 提供"查看相关策略"按钮，点击后展示方向一致的策略列表
- 此功能避免家长在不同方向间摇摆，浪费干预精力

**边界情况**:
- 档案不完整时使用默认年龄/诊断模板
- 策略库覆盖不足时记录日志，运营补充
- 朗读话术TTS语速0.8x，语气温和

## 模块3：紧急安抚模式

**功能概述**: 在孩子情绪崩溃时提供零思考引导界面，先稳定家长情绪，再逐步给出安抚策略，支持桌面小组件和智能手表联动。

**UX流程**:
1. **触发方式**:
   - App内"SOS"暖橙色按钮（底部固定）
   - **PWA快捷方式**: 添加到主屏幕的快捷图标，一键打开紧急模式（替代原生桌面小组件）
   - **锁屏通知快捷操作**: 紧急通知推送时，支持锁屏直接点击进入紧急模式
   - **智能手表联动**: 通过HealthKit/Google Fit读取心率（MVP降级方案）
   - **系统级快捷方式**: iOS快捷指令、Android快捷方式

**桌面小组件说明**: Web应用无法实现原生Widget（如iOS WidgetKit），故MVP阶段使用以下替代方案：

| 方案 | 实现方式 | 效果 |
|------|----------|------|
| PWA快捷方式 | 添加到主屏幕 | 点击图标直接进入紧急模式 |
| 锁屏快捷操作 | 通知推送时显示操作按钮 | 锁屏状态下一键触发 |
| 系统快捷方式 | iOS快捷指令/Android快捷方式 | 语音或手势触发 |

**P3远期规划**: 通过Capacitor打包原生壳，实现真正的桌面小组件。

2. 进入界面：全屏深蓝灰背景，第一屏"先深呼吸一次"+呼吸动画（4秒扩/4秒缩，轻微震动）

3. **分级响应选择**（深呼吸动画之后）：
   - 显示快速选择页面："当前情况属于："
   - 🟢 **一般行为问题** — 如哭闹、拒绝配合、发脾气
   - 🟡 **情绪爆发升级** — 如尖叫、摔东西、打滚
   - 🔴 **有伤害风险** — 如自伤行为（撞头、咬自己）、攻击他人
   - 选择不同级别后差异化响应：
     - 🟢：以常规安抚策略为主（当前设计）
     - 🟡：增加降级策略和感官调节工具，策略更注重情绪降温
     - 🔴：优先包含安全处置指引，自动附带紧急求助信息（附近医院、派出所位置）

4. 3秒后自动展示第一条安抚策略（大字），每15秒轮播下一条，可手动滑动切换
5. **路人管理话术**: 提供应对周围路人围观的话术模板
6. 退出：点击"结束"或10分钟无操作自动退出，保存会话

**紧急模式退出后的立即反馈**:
- 退出紧急模式后，不立即显示回顾表单
- 第一屏显示简短的正向肯定文字："刚才的情况很艰难，但你撑过来了。你做得足够好。"
- 3秒后自动消失，或点击"我知道了"关闭
- 提供一键跳转"能量加油站"的入口

**30分钟后的回访优化**:
- 增加"此刻的感受"选择：😌已平静 / 😔还在低落 / 😤依然愤怒
- 选择"😌已平静"才展开回顾表单
- 选择"😔还在低落"或"😤依然愤怒"时，推送心理支持内容或一键跳转"能量加油站"

**能量加油站**:
- 收藏所有"微光时刻"、里程碑成就、正向反馈
- 紧急模式结束后可一键跳转至此
- 目的：让家长在被挫败感淹没时，能快速重拾信心

**感谢卡收藏规则**（隐私边界）:
- 感谢卡默认**不自动**进入能量加油站
- 家长可选择将某张已发送的感谢卡手动"收藏到加油站"
- 收藏操作**对配偶不可见**，仅家长本人可查看

**智能手表联动（MVP阶段降级方案）**:

| 功能 | MVP实现 | 说明 |
|------|---------|------|
| 心率读取 | 读取家长静息心率 | 通过系统健康API获取，用于情绪评估 |
| 情绪预警 | 心率异常时提醒 | 心率超过阈值时，建议家长先进行深呼吸 |

**边界情况**:
- 完全离线可用，紧急策略预缓存到本地
- 紧急模式中来电处理，通话结束后返回当前策略页
- 事后回顾最多提醒2次，超过则不再打扰

**预防性预警（V2规划）**:

- 系统基于历史行为数据，识别高风险时段和场景
- 在高风险时段前30分钟推送预警通知
- 预警内容示例：
  - "根据历史记录，周一早晨通常是情绪爆发高发时段。建议提前10分钟预告活动转换。"
  - "今天下午有雷雨天气，历史上孩子在天气变化时容易焦虑。准备好感官安抚物品。"
- 家长点击预警可直接进入预防策略页面
- 预防性预警开关默认关闭，用户可在设置中开启

**实时协作支援（V3规划）**:

- 紧急模式下提供"邀请支援"按钮，位于策略页面右上角
- 可向预设的紧急联系人或当前在线康复师发送支援请求
- 支援者收到通知后，可查看当前紧急模式的策略和历史行为摘要（需获得家长授权）
- 支援者可通过文字或语音提供实时建议
- 支援会话全程加密，结束后自动关闭共享权限

## 模块4：康复师沟通周报自动生成

**功能概述**: 每周自动汇总行为记录、策略效果，生成图文周报，支持分享给康复师并在线评论，康复师可免注册通过H5查看。

**UX流程**:
1. 每周六晚20:00生成周报（可自定义生成时间），推送通知
2. 周报展示：趋势箭头、环形图、时间线、策略排行榜、AI评语、"家长最关心的3个问题"
3. **一键分享**: 生成微信/H5分享链接，康复师免注册查看
4. **康复师专业版**:
   - 学员管理看板：查看所有学员周报、筛选、排序
   - 长期趋势图：跨周对比、月度/季度统计
   - AI干预建议：基于学员数据自动生成干预方案建议
   - 个人品牌主页：展示专业背景、擅长领域、家长好评

**康复师激励机制**:

| 激励方式 | 说明 | 实现方式 |
|----------|------|----------|
| 收入挂钩 | 与康复机构合作，将平台使用情况纳入机构内部绩效考核参考 | 提供机构管理后台 |
| 继续教育学分 | 与省级康复协会或中国残联合作，完成培训课程可获得官方认可的继续教育学分 | 与专业机构合作开发认证课程 |
| 个人品牌展示 | 康复师可在平台展示专业背景、擅长领域、家长好评 | 建立评价体系，形成正向循环 |

**康复师专业评分计算**:
- 基础分：100分
- 加分项：周报查看率(+10分/周)、评论回复及时率(+5分/次)、家长好评率(+15分/月)
- 减分项：连续2周未查看周报(-10分)、家长投诉(-20分/次)

**异步视频反馈闭环**:

完整闭环流程：

1. **家长上传视频**: 在记录详情页选择"上传视频"，拍摄/上传一段干预实操视频（最长3分钟），上传时自动压缩至720p以内
2. **视频随周报分享**: 视频作为周报附件，随分享链接一起发送给康复师
3. **康复师时间轴标注**: 康复师在H5查看页播放视频，可在时间轴上添加标注（如"00:32-00:45 这里辅助等级过低"），标注点以标记显示在进度条上
4. **康复师评论**: 康复师添加语音/文字评论，评论与视频时间轴关联
5. **家长查看反馈**: 家长App收到通知，查看视频标注和评论，标记"已理解"或"有疑问"
6. **系统记录**: 每次视频督导互动被记录，下次周报自动体现"本月完成X次视频督导"

**周报"未来一周预测"板块**:

在周报结构中增加"下一周关注"板块：

- 基于过去4周行为趋势，AI分析预测下周可能的高风险时段和场景
- 推送1-2条预防性建议，例如：
  - "根据历史数据，周一早晨是情绪爆发高发时段，建议提前10分钟预告活动转换"
  - "上周三在超市出现两次行为问题，建议本周三前往超市前先做视觉提示"
- 预测置信度标注（高/中/低），让家长了解推荐的可靠程度
- 该板块位于周报末尾，作为"本周回顾→下周关注"的自然过渡

**边界情况**:
- 记录过少(<3条)时显示简化报告，仅包含基础统计
- 分享链接有效期30天，家长可手动延长或撤销
- 康复师评论不可删除家长原始数据，仅可编辑自己的评论

## 模块5：全生涯规划与未来模拟器

**功能概述**: 帮助家长了解各阶段发展里程碑，设置和追踪目标，提供未来场景模拟和法律/财务规划指引。

**UX流程**:
1. 生涯时间轴：横向滑动，阶段：刚确诊→早期干预→学前→学龄→青春期→青年→成年
2. 里程碑为可点亮的星星，点击记录达成故事，支持上传照片/视频
3. 目标设定：选择领域（社交、生活自理、学习、职业），AI分解为10-20个子步骤，进度条可视化
4. **未来模拟器**:
   - 输入能力评估（当前能力水平、支持程度）
   - 展示三种支持水平下的未来生活场景：基础支持、中等支持、全面支持
   - 每种场景附带真实案例故事链接，增加可信度
5. **法律规划渐进式对话引导**:
   - 第一步："如果发生意外，你希望谁临时照顾孩子？"
   - 第二步："你是否已经指定了法定监护人？"
   - 第三步："你是否考虑过孩子成年后的监护安排？"
   - 第四步："你是否了解特殊教育相关的法律权益？"

**边界情况**:
- 里程碑数据缺失时，显示通用里程碑建议

## 模块6：家庭系统支持中心

**功能概述**: 照顾者心理健康支持、配偶感谢卡AI生成、隔代沟通三种话术模板、手足专属时光活动推荐。

**UX流程**:
1. **情绪签到**: 每日表情选择（5种情绪），连续低落触发共情消息和正念引导
2. **配偶感谢卡AI生成**:
   - 每周五推送感谢卡生成提醒
   - AI基于近期家庭互动记录生成3个版本草稿：温情简洁版、具体细节版、幽默轻松版
   - 用户可编辑、保存或分享给配偶
3. **隔代沟通三种话术模板**:
   - 输入场景描述，AI输出三种风格回应：温和说服型、科普教育型、边界设定型
4. **手足专属时光活动推荐**:
   - 每月提醒一次，推荐基于年龄的互动活动
   - 支持记录活动完成情况，生成"手足时光"相册
5. **CBT思维记录**: 引导完成5步流程（情境→想法→情绪→证据→替代想法），支持分步自动保存

**边界情况**:
- 情绪连续低落7天，推送心理援助热线
- 家庭模块内容仅本人可见，配偶需通过分享链接查看感谢卡

## 模块7：家长成长体系

**功能概述**: 建立统一的家长能力成长追踪体系，通过干预能力指数衡量家长在育儿过程中的硬实力提升。

**干预能力指数 (Intervention Capability Index)**:

| 维度 | 权重 | 计算方式 |
|------|------|----------|
| 策略使用频率 | 25% | 近30天使用策略次数 / 目标15次 |
| 策略成功率 | 25% | 策略反馈为"有效"的比例 |
| 情绪调节能力 | 20% | 使用深呼吸等情绪调节工具的次数 |
| 记录习惯 | 15% | 近30天记录天数 / 30 |
| 学习活跃度 | 15% | 阅读文章、完成课程的数量 |

**辅助参考维度**: 周报查看率、分享互动次数（不纳入主评分）

**能力等级体系**:

| 等级 | 名称 | 分数范围 |
|------|------|----------|
| L1 | 新手家长 | 0-30 |
| L2 | 成长家长 | 31-60 |
| L3 | 熟练家长 | 61-80 |
| L4 | 专业家长 | 81-95 |
| L5 | 专家家长 | 96-100 |

**成长可视化——"成长树"设计**:
- 每解锁一项新技能，树上长出一片新叶
- 每达到一个新等级，树上开出一朵花
- 点击树叶可查看对应成就的详情

**反馈体系层级关系**:

| 反馈类型 | 推送时机 | 数据颗粒度 |
|----------|----------|------------|
| 微光时刻 | 当天发生有效策略反馈 | 单条事件 |
| 周报家长反馈 | 每周六周报生成时 | 7天数据 |
| 月度干预小结 | 每月1日 | 30天整体趋势 |

**仪式感与阶段性庆典**:
- **里程碑庆典动画**: 达成长期目标推送动画+成长证书
- **年度回顾报告**: 每年12月31日生成精美H5页面
- **生日祝福**: AI生成"写给孩子的信"

**家长退出计划与毕业机制**:

当干预能力指数达到L4（专业家长）并保持3个月以上，系统触发"毕业评估"流程：

1. **毕业评估触发**:
   - 检测条件：干预能力指数≥81分连续3个月
   - 系统推送"毕业评估邀请"，告知家长已具备独立应对能力
2. **毕业报告生成**:
   - 推送一份"您已具备独立应对能力"的报告
   - 报告包含：干预能力指数成长曲线、关键能力变化、孩子的进步记录
   - 鼓励家长减少App依赖，转为每周回顾模式
3. **角色转换**:
   - 提供"帮助其他家长"的入口，引导用户从"被帮助者"转变为"帮助者"
   - 可申请成为支持圈引导者、深夜聊天室志愿者
   - 授予"星伴导师"专属徽章（在成长树、个人主页展示）
4. **毕业后的持续服务**:
   - 降级为"每周回顾"模式，每月推送一次成长回顾
   - 紧急模式、安全防走失等核心功能保留
   - 可随时重新激活完整功能

## 家长学院（合并至模块7：家长成长体系）

**功能概述**: 系统化的家长培训平台，提供从入门到进阶的行为干预课程。

**课程体系**:

| 系列 | 目标用户 | 内容主题 | 课时数 |
|------|----------|----------|--------|
| 入门系列 | 新诊断家长 | 自闭症基础知识、诊断流程、家庭干预入门 | 8节 |
| 进阶系列 | 有一定经验的家长 | 行为干预技巧（ABA/DIR）、情绪管理、沟通策略 | 12节 |
| 专家系列 | 资深家长/康复师 | BCBA深度课程、IEP制定、家庭康复计划设计 | 16节 |

**内容形式**:
- **短视频**: 每节视频不超过10分钟
- **图文解读**: 配合视频的详细文字说明和图解
- **互动测验**: 每节课后设置3-5道选择题
- **实操练习**: 课后布置实践任务

**实操考核**:
- 家长可提交自己实施策略的视频或文字记录
- AI进行基础评分（检查是否包含策略关键步骤）
- 优秀作业可被选为"家长榜样"案例

**学习积分体系**:
- 完成课程：+10积分
- 通过测验：+5积分
- 提交实操作业：+20积分
- 作业被评为优秀：+50积分
- 积分可兑换严选商城优惠券或免费会员天数

## 模块8：财务规划与防骗指南

**功能概述**: 追踪开支、补贴管理、保险报销引导、防骗预警，支持发票OCR自动归类和社区举报机制。

**UX流程**:
1. **记账**: 手动输入或发票OCR自动归类
2. **补贴地图时间轴**: 输入城市/诊断类型，生成补贴时间轴清单
3. **报销助手**: 根据保险政策提示材料清单
4. **防骗预警**: 社区举报机制，可疑信息审核

**边界情况**:
- 防骗预警注明信息来源和审核状态
- OCR识别失败率超过50%时，提醒用户手动输入

## 模块9：安全与防走失系统

**功能概述**: 安全身份卡、防走失预案、安全技能训练记录、走失紧急模式，支持自动推送和数字信任联系人。

**UX流程**:
1. **安全身份卡**: 生成包含关键信息的身份卡，支持小程序码分享
2. **防走失预案**: 设置紧急联系人、走失后行动指南
3. **安全技能训练**: 记录孩子安全技能掌握情况
4. **走失紧急模式**: 一键触发，自动推送求助信息给信任联系人

**边界情况**:
- 训练步骤需专业审核后上线
- 走失紧急模式触发后，用户可随时取消推送
- 小程序码有效期为1年，到期自动提醒更新

## 模块10：同伴联结与孤独感破除

**功能概述**: 智能匹配匿名同伴、结构化故事分享、支持圈、深夜陪伴临时聊天室，支持匿名渐进解锁机制。

**UX流程**:
1. **智能匹配**: 基于兴趣、孩子年龄、诊断类型匹配匿名同伴
2. **故事分享**: 使用结构化模板分享故事（我的故事、孩子的进步、挑战与突破、温馨时刻）
3. **支持圈**: 加入主题支持圈，参与讨论和互助
4. **深夜陪伴临时聊天室**: 凌晨0:00-5:00开放"今夜醒着"状态，匿名临时聊天室

**匿名渐进解锁机制**:
- 解锁需双方同意
- 每级解锁可随时撤回
- 撤回后恢复到上一级匿名状态

**深夜聊天室管理员职责定义**:

| 阶段 | 管理员类型 | 职责范围 |
|------|------------|----------|
| 初期（0-6个月） | AI自动监控 | 敏感词过滤、用户举报处理 |
| 中期（6-18个月） | 运营团队值班 | 处理AI审核队列中的灰色地带 |
| 长期（18个月+） | 家长志愿者 | 担任"夜间守护者"，协助维护秩序 |

**边界情况**:
- 严格反骚扰和举报机制，多次违规者封禁账号
- 内容审核+敏感词过滤，违规内容自动拦截
- 深夜聊天室消息即焚，不可恢复

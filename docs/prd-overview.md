## 1. 项目概述

### 1.1 产品定位

星伴是一款面向自闭症儿童家长的综合性支持平台，通过AI驱动的行为分析、个性化策略推荐、紧急安抚指导等功能，帮助家长科学应对育儿挑战，建立长期发展规划。

### 1.2 核心价值

- **即时支持**: 在孩子行为问题发生时提供实时指导
- **数据驱动**: 通过记录和分析帮助家长了解孩子发展趋势
- **专业连接**: 连接康复师和家长，建立专业沟通桥梁
- **长期规划**: 帮助家长制定全生涯发展规划

### 1.3 目标用户

- 自闭症儿童家长（核心用户）
- 康复师/特教老师（专业用户）
- 其他照顾者（祖父母、保姆等）

## 2. 市场分析

### 2.1 市场规模

- 全球自闭症患病率约1/68，中国约有超过1000万自闭症人群
- 每年新增确诊儿童约10万+
- 家长对专业支持的需求持续增长

### 2.2 竞争格局

| 竞品 | 优势 | 劣势 |
|------|------|------|
| 传统康复机构 | 专业度高 | 价格昂贵、地域限制 |
| 在线课程平台 | 知识丰富 | 缺乏个性化、互动性弱 |
| 家长社群 | 情感支持 | 信息质量参差不齐 |
| 医疗类App | 专业性强 | 侧重诊断，缺乏日常指导 |

### 2.3 市场机会

- AI技术降低个性化支持门槛
- 移动互联网普及，随时随地获取支持
- 政策支持特殊教育发展

## 4. 产品架构

### 4.1 功能模块总览

| 模块 | 功能描述 | 优先级 |
|------|----------|--------|
| 模块0 | 儿童数字孪生档案（新增） | P0 |
| 模块1 | 一键记录与AI结构化（拍照/语音/文字，状态机驱动的3次语音识别容错，历史行为图谱） | P0 |
| 模块2 | 情景化即时策略推荐（3条个性化策略，反馈学习，技能泛化追踪） | P0 |
| 模块3 | 紧急安抚模式（离线可用，PWA快捷方式，智能手表联动，心理修复，能量加油站） | P0 |
| 模块4 | 康复师沟通周报自动生成（免注册H5查看，评论双向同步，康复师专业版看板，激励机制） | P0 |
| 模块5 | 全生涯规划与未来模拟器（多种支持水平展示，法律规划渐进式引导） | P1 |
| 模块6 | 家庭系统支持中心（配偶感谢卡AI生成，隔代沟通三种话术，手足专属时光，CBT思维记录） | P1 |
| 模块7 | 家长成长体系（含成长树、家长学院、毕业机制） | P1 |
| 模块8 | 财务规划与防骗指南 | P1 |
| 模块9 | 安全与防走失系统 | P2 |
| 模块10 | 同伴联结与孤独感破除 | P2 |

### 4.2 用户旅程

```
注册 → 创建儿童档案 → 首次记录 → 获取策略 → 尝试策略 → 反馈效果 → 查看周报 → 分享给康复师
```

### 4.3 零负担交互设计原则

**核心理念**: 特殊儿童家长每天都处于高压力、低精力的状态。所有功能设计必须遵循"零负担"原则——不增加家长的心理负担和操作负担。

**具体规则**:

| 原则 | 说明 | 示例 |
|------|------|------|
| 一句话模式 | 所有功能必须提供"一句话"或"一键"完成的方式 | 行为记录允许只点一个表情就完成，策略反馈允许只点一个emoji就提交 |
| 不催促原则 | 连续3天未记录时，不推送催促通知 | 推送"我们知道你很累，没关系，随时回来" |
| 倦怠检测 | 若用户使用频率骤降（如连续7天未打开），自动切换为"轻量模式" | 首页只展示最核心的"记一笔"和"紧急模式"两个按钮，降低信息负担 |
| 语音唤醒 | 紧急模式下支持语音唤醒（长期规划） | 喊"星伴帮我"即可激活紧急模式，完全解放双手 |
| 正向优先 | 所有反馈以正向为主，避免任何指责性或压力性话术 | 使用"你做得很好"而不是"你应该这样做" |

## 5. 风险与缓解措施

### 5.1 风险清单

| 风险类型 | 风险描述 | 缓解措施 |
|----------|----------|----------|
| AI幻觉风险 | AI生成错误策略 | 详见第六章AI可靠性保障体系（五层防线：知识库约束、多模型交叉校验、安全护栏、用户反馈闭环、人机协作兜底） |
| 数据安全 | 用户隐私数据泄露 | 端到端加密，最小权限原则，合规审计，数据主权声明 |
| 运营风险 | 内容质量参差不齐 | 专家审核流程，社区规范，举报机制 |
| 商业风险 | 用户付费意愿低 | 免费版引流，7天专业版体验，分层定价，价值展示 |
| 合规风险 | 医疗类App监管 | 明确产品定位为"支持工具"而非"医疗诊断"，遵守PIPL/GDPR |

### 5.2 危机响应机制

- **舆情监控**: 实时监控社交媒体、应用商店评论
- **快速响应**: 24小时内响应用户投诉和负面反馈
- **分级处理**: 根据问题严重程度启动不同级别响应
- **事后复盘**: 重大事件后进行复盘，完善流程
